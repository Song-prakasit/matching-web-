# การสำรองข้อมูลของระบบ (สำหรับผู้ดูแลระบบ/IT)

## ข้อมูลหลักอยู่ที่ฐานข้อมูลเดิม

ข้อมูลใบสั่งยา ผู้ใช้ และรหัสผ่านอยู่ใน SQL Server (`IPharmaDB`, `HAD.ms_users`) ซึ่งใช้ร่วมกับระบบเดิม
ให้ใช้การสำรองฐานข้อมูลตามปกติของโรงพยาบาล ระบบเว็บนี้ไม่ได้สำรองส่วนนี้ให้

## ไฟล์ที่ระบบเว็บเก็บเอง: `server/data/`

| ไฟล์ | เก็บอะไร | ถ้าหาย |
|---|---|---|
| `branding.json` | โลโก้ ชื่อโรงพยาบาล หัวข้อหน้า login | กลับไปค่าเริ่มต้น ตั้งค่าใหม่ได้ |
| `audit.log` | ประวัติการเข้าสู่ระบบ การสแกน การยกเลิก การแก้ตั้งค่า | **กู้คืนไม่ได้** ควรสำรองเสมอ |
| `lockouts.json` | ตัวนับการป้อนรหัสผิด/บัญชีที่ถูกล็อก | ตัวนับรีเซ็ต ไม่เสียหาย |

ไฟล์ `server/.env` เก็บ `JWT_SECRET`, รหัสเชื่อมฐานข้อมูล และ `ADMIN_USER_IDS` ควรสำรองไว้ในที่ปลอดภัย (ไม่ใส่ใน git)

## วิธีสำรอง

คัดลอกโฟลเดอร์ `server/data/` และไฟล์ `server/.env` ไปเก็บนอกเครื่อง อย่างน้อยวันละครั้ง เช่นด้วยงานตั้งเวลา

macOS / Linux:
```bash
tar czf matching-backup-$(date +%F).tgz server/data server/.env
```

Windows (PowerShell):
```powershell
Compress-Archive -Path server\data, server\.env -DestinationPath "matching-backup-$(Get-Date -Format yyyy-MM-dd).zip"
```

## กู้คืน

หยุด server วางไฟล์กลับที่เดิม แล้วเปิด server ใหม่

## ข้อควรระวัง

- `audit.log` โตขึ้นเรื่อย ๆ ควรตรวจขนาดเป็นระยะ และเก็บไฟล์เก่าตามนโยบายของโรงพยาบาล
- `audit.log` มีชื่อผู้ใช้และเลขใบสั่ง จัดเก็บเป็นความลับเหมือนข้อมูลผู้ป่วย
